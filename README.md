# Point Cloud Registration from First Principles

In this repository, we explore point cloud registration and cover the fundamental concepts needed to understand how registration methods work.

We start with the basics of rigid transformations, then move on to correspondence search and different strategies for aligning two point clouds. We also introduce some well-known registration methods commonly used in robotics and 3D perception.

Finally, we include benchmarks and open-source implementations to compare different approaches in practice.
